# InfinitySwap (Bitfinity Network)

> InfinitySwap is now Bitfinity Network — a next-generation Ethereum Virtual Machine (EVM) that serves as a Layer 2 for Bitcoin and Bitcoin on-chain assets, built on the Internet Computer (ICP). It delivers 1000+ TPS EVM execution with full Ethereum tooling compatibility (MetaMask, Remix, Hardhat) via a standard Ethereum JSON-RPC endpoint, and supports bridging BTC, ckBTC, and other assets. Backed by Polychain.

## API

- [Bitfinity EVM JSON-RPC](https://docs.bitfinity.network/): Standard Ethereum JSON-RPC 2.0 endpoint at https://mainnet.bitfinity.network — Chain ID 355110 (0x56b26), client evm_core/0.2.0. Public, keyless; supports eth_*, net_*, and web3_* method namespaces. Compatible with ethers.js, web3.js, MetaMask, Hardhat, and Remix.
